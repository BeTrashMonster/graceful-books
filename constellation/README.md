# The Constellation ✨

> A visual spider-graph presentation tool mapping the entire Graceful Books financial ecosystem

## What is this?

The Constellation is an **interactive network visualization** showing how all the financial products connect together. Think Obsidian's graph view, but for your business vision!

- **Center Hub:** Graceful Books (Bookkeeping) - Everything unfurls from here
- **Radiating Modules:** Budgeting, Debt Management, Service Provider & Job Costing, CPG Tool
- **Separate Orbit:** Fractional CFO/Accountant Portal (connects but operates independently)

## Features

✨ **Interactive Spider Graph** - Click and drag nodes, zoom in/out
💜 **Royal Purple, Green, Gold Theme** - Fun, quirky, rebellious vibes
📊 **Click for Details** - See pricing, features, standalone vs. integrated
💚 **Charity Built-In** - Every subscription includes $5/month donation

## Quick Start

```bash
# Install dependencies
npm install

# Start the dev server (opens at http://localhost:5174)
npm run dev

# Build for production
npm run build
```

## Purpose

This is a **presentation tool** for stakeholder meetings, CTO pitches, and vision communication. It's NOT part of the main Graceful Books app - it's a standalone visualization to show the big picture.
